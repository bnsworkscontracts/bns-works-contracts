# BNS Works Contracts Private Limited

This is the corporate presentation website for BNS Works Contracts Private Limited. It presents the company’s construction, civil works and infrastructure capabilities, with direct phone and email contact options.

## Built with

- Next.js
- React
- TypeScript
- pnpm

## Run the website locally

1. Install the project dependencies:

   ```bash
   pnpm install
   ```

2. Start the local development server:

   ```bash
   pnpm dev
   ```

3. Open `http://localhost:3000` in a browser.

## Create a production build

Run the following before deploying to check that the website can be built for production:

```bash
pnpm build
```

## Main content and media files

- Company facts: `src/data/company.ts`
- Services: `src/data/services.ts`
- Website pages and sections: `src/main.tsx`
- Site styling: `src/styles.css`
- BNS logo: `public/images/brand/bns-logo.png`
- Website imagery: `public/images/general/`

The construction visuals are clearly marked as AI-generated illustrations and are not presented as BNS project photography.
